map-engine

A small TypeScript library that turns a PNG of flat-color regions and a JSON file into an interactive map. A recolor is one write to a GPU palette, and pathfinding runs in a Web Worker, so the frame never blocks. It weighs about 16 kB gzipped.

NS air quality dashboard

A React and TypeScript dashboard of sixteen years of hourly air quality readings from Nova Scotia's monitoring stations. Each reading is judged against its official limit, and every missing hour shows as missing. The map is drawn with map-engine.
